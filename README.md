# 世田谷区 ごみ分別クイズ（gomi-quiz）

## 概要

世田谷区（東京都）のごみ分別データを題材にした、**1問1答形式の学習クイズWebアプリ**です。

分かりにくいごみの分別に不安を抱えている方や、子どもから大人まで、誰もが楽しく学べることを目的としています。

## 遊び方

1. 画面に表示されたごみ・品目の問題を読みます。
2. 下にある回答ボタン（6つ）から、正しい分別のカテゴリを選びます。
3. 正解・不正解を判定し、正解の場合は「正しい分別方法」の解説を表示します。
4. 連続正解を更新し、自己ベストを更新すると「自己ベスト更新！」と表示します。
5. 全問（165問）をプレイすると、正解数・正答率・間違えた問題数などの結果画面を表示します。
6. 間違えた問題は、回答・正解・備考・有料区分を確認できる**復習**リストとして扱えます。
7. PC・スマートフォンともにキーボード（1〜6キー）やボタン操作に対応しています。
